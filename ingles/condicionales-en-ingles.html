Los condicionales en inglés: zero, first y second

Los condicionales expresan una condición y su resultado con if. En inglés hay varios tipos según lo real o imaginario que sea.

Zero conditional: hechos

If + presente, presente: If you heat ice, it melts. Para verdades generales y hábitos.

First conditional: posibilidad real

If + presente, will + verbo: If it rains tomorrow, I will stay at home. Para situaciones posibles en el futuro.

Second conditional: situaciones imaginarias

If + pasado, would + verbo: If I were rich, I would travel the world. Se usa were con todas las personas y nunca would después de if.

Ejemplos con audio

Si calientas hielo, se derrite.
If you heat ice, it melts.
Si llueve, me quedaré en casa.
If it rains, I will stay at home.
Si fuera rico, viajaría.
If I were rich, I would travel.
Si estudias, aprobarás.
If you study, you will pass.
Si tuviera tiempo, te ayudaría.
If I had time, I would help you.
Yo en tu lugar, la llamaría.
If I were you, I would call her.

Errores comunes

  • If it will rain, I stay. → If it rains, I will stay.
    Después de if no va will.
  • If I would have time, I help. → If I had time, I would help.
    Nunca would después de if.
  • If I was rich... → If I were rich...
    En el segundo condicional se prefiere were.

Preguntas frecuentes

¿Se puede usar will después de if?

No. Después de if va presente (first) o pasado (second).

¿Cuándo uso would?

En el segundo condicional, para situaciones imaginarias.
