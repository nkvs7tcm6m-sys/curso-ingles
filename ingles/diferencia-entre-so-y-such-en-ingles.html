Diferencia entre so y such en inglés

So y such se usan para enfatizar y se traducen como tan. Lo que cambia es lo que va detrás: so con adjetivos y adverbios; such con sustantivos.

So + adjetivo o adverbio

So va antes de un adjetivo o adverbio solo: The film was so boring. She speaks so quickly. I'm so tired.

Such + sustantivo

Such va antes de un sustantivo, con o sin adjetivo: It was such a boring film. They are such nice people. Si es singular contable, lleva a/an: such a day.

So…that y such…that

Para consecuencias: The film was so boring that I fell asleep. It was such a long day that I went to bed early. También: so much / so many (tanto/tantos): so much work, so many people.

Ejemplos con audio

Estoy tan contento de verte.
I'm so happy to see you.
Fue un día tan bonito.
It was such a beautiful day.
Ella es tan amable.
She is so kind.
Son tan buenos amigos.
They are such good friends.
El examen fue tan difícil que nadie terminó.
The test was so difficult that nobody finished.
Tenemos tantas cosas que hacer.
We have so many things to do.

Errores comunes

  • It was so a nice day. → It was such a nice day.
    Antes de a + sustantivo se usa such.
  • She is such tired. → She is so tired.
    Antes de un adjetivo solo: so.
  • I have such much homework. → I have so much homework.
    Con much y many se usa so.

Practica ahora

Preguntas frecuentes

¿Cómo traduzco tan…que?

Con so…that o such…that: so tired that I slept.

¿So y very son iguales?

So es más enfático y se usa para consecuencias o emoción: so beautiful!
