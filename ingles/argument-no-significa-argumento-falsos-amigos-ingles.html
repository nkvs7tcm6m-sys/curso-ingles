Argument no significa argumento: falso amigo en inglés

Argument parece argumento, pero muy a menudo significa discusión o pelea verbal. También puede ser una razón que defiende una opinión. Para el argumento de una película, se dice plot.

Argument: discusión

Un argument es una conversación con enfado: They had an argument about money. Verbo: argue: Don't argue with your brother. Es negativo si se trata de un conflicto.

Argument: razón

También puede ser una razón para defender una idea: That's a strong argument. There are good arguments for and against. En este sentido sí se parece al español.

Argumento de una historia

El argumento de una película o libro es the plot: The plot is very complicated. La trama secundaria es subplot. El tema es theme.

Ejemplos con audio

Tuvieron una discusión ayer.
They had an argument yesterday.
No discutas conmigo.
Don't argue with me.
Es un buen argumento.
That is a good argument.
El argumento de la película es interesante.
The plot of the film is interesting.
A menudo discutimos de política.
We often argue about politics.
Defendió con firmeza el cambio.
He made a strong argument for change.

Errores comunes

  • The argument of the film is exciting. → The plot of the film is exciting.
    El argumento de una historia es plot.
  • I had an argument with the exam. → I had a problem with the exam.
    Argument implica una discusión o razonamiento.
  • We argumented for hours. → We argued for hours.
    El verbo es argue.

Preguntas frecuentes

¿Argument y discussion son iguales?

No. Discussion es una conversación; argument suele implicar desacuerdo.

¿Cómo se dice un argumento a favor?

An argument in favour of... o an argument for...
