Diferencia entre used to y would en inglés

Con used to y would hablamos de cosas que hacíamos en el pasado y que ya no hacemos. Se parecen mucho, pero hay una diferencia importante: used to sirve para hábitos y estados; would, solo para hábitos.

Used to: hábitos y estados

Used to + verbo sirve para acciones repetidas y también para situaciones: I used to play football. She used to have long hair. We used to live in Madrid.

Would: solo hábitos repetidos

Would + verbo se usa para acciones repetidas que recuerdas con nostalgia: Every summer we would go to the beach. No se usa con verbos de estado: no se dice I would have a bike.

Negativa y pregunta

Con used to, en negativas y preguntas se pierde la -d: I didn't use to smoke. Did you use to live here? Además, be used to (+ -ing) es otra cosa: estar acostumbrado.

Ejemplos con audio

Tocaba la guitarra.
I used to play the guitar.
Visitábamos a nuestros abuelos cada domingo.
We would visit our grandparents every Sunday.
Ella vivía en París.
She used to live in Paris.
Antes no le gustaban las verduras.
He didn't use to like vegetables.
¿Antes llevabas gafas?
Did you use to wear glasses?
De niño leía antes de dormir.
When I was a child, I would read before bed.

Errores comunes

  • I would have a dog when I was young. → I used to have a dog when I was young.
    Have es un verbo de estado: no se usa con would.
  • She didn't used to smoke. → She didn't use to smoke.
    Después de didn't, el verbo vuelve a la forma base: use to.
  • I'm used to wake up early. → I'm used to waking up early.
    Be used to va seguido de -ing.

Practica ahora

Preguntas frecuentes

¿Puedo usar would con verbos como be o have?

No para estados. Usa used to: I used to be shy.

¿Es lo mismo used to que be used to?

No. Used to + verbo = hábito pasado. Be used to + -ing = estar acostumbrado.
