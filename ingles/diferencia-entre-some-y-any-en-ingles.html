Diferencia entre some y any en inglés

Some y any sirven para hablar de una cantidad no exacta: algo de, algunos o ninguno. Normalmente some va en afirmativas y any en negativas y preguntas, pero hay excepciones importantes.

Some en afirmativas

Usamos some en frases afirmativas: I have some friends in London. There is some milk in the fridge. Sirve con plurales e incontables.

Any en negativas y preguntas

Usamos any en negativas y en preguntas: I don't have any money. Is there any milk? Have you got any brothers? Con 'not any' decimos ninguno.

Excepciones: ofrecer y pedir

En ofrecimientos y peticiones se usa some aunque sea pregunta: Would you like some tea? Can I have some water? Y en afirmativas, any significa cualquiera: You can take any book.

Ejemplos con audio

Necesito algo de ayuda.
I need some help.
No tenemos huevos.
We don't have any eggs.
¿Tienes alguna pregunta?
Do you have any questions?
¿Quieres un poco de café?
Would you like some coffee?
No quedan entradas.
There aren't any tickets left.
Puedes elegir cualquier color.
You can choose any colour.

Errores comunes

  • I don't have some money. → I don't have any money.
    En negativas se usa any.
  • Is there some milk? → Is there any milk?
    En preguntas normales usa any.
  • Would you like any tea? → Would you like some tea?
    En ofrecimientos se usa some.

Practica ahora

Preguntas frecuentes

¿Puedo usar any en afirmativas?

Sí, pero con otro significado: cualquiera. You can ask any teacher.

¿Se usa some con incontables?

Sí: some water, some rice, some advice.
